🌐 Webster AI
📌 Overview

Webster AI is a student-focused web platform designed to help students plan their career and internship journey effectively. The platform provides internship prediction, CV analysis, personalized roadmaps, eligibility checking, internship tracking, and real-time guidance — all in one place.

🎯 Problem Statement

Students often struggle to find suitable internships and plan their career paths due to the lack of personalized guidance, structured planning tools, and real-time support.

💡 Solution

Webster AI addresses this problem by offering an integrated platform that analyzes student profiles, predicts suitable internships, evaluates resumes, generates learning roadmaps, tracks internship deadlines, and provides instant assistance through a chatbot.

🚀 Features

Internship Prediction
Suggests suitable internship roles based on user skills, GPA, and interest area.

CV Analyzer
Allows users to upload their CV and receive feedback on strengths and areas for improvement.

Personalized Roadmap
Generates a step-by-step roadmap based on user profile and analysis results.

Profile Management
Collects academic and experience-related details for better personalization.

Eligibility Checker
Calculates eligibility percentages for top companies such as Microsoft and Google.

Internship Tracker
Helps users track internship deadlines and remaining days.

AI Chatbot
Answers internship and career-related queries in real time.

Developer & Feedback Page
Displays project details and allows users to submit feedback.

🧱 Architecture Overview

User Interface: Web-based frontend

Application Logic: JavaScript-based processing

Database: Firebase Realtime Database

AI Integration: Google Gemini API (partial)
