# WebsterAI-AICareerGuide
Webster AI is a student-focused web platform designed to simplify internship preparation and career planning for students. The platform provides an integrated solution that includes internship prediction based on skills, GPA, and interests, CV analysis with strengths and improvement suggestions, personalized career roadmaps, profile-based eligibility calculation for top companies, internship deadline tracking, and real-time guidance through a chatbot. Built using web technologies and Google tools, Webster AI serves as a Minimum Viable Product (MVP) aimed at offering structured, personalized, and accessible career guidance for students, especially early-stage learners.
